# Demo PWA

A progressive web app prototype built with Next.js and TypeScript.

## Overview

This project explores interactive breathing experiences, progressive web app capabilities, offline support, and communication between a web application and a native Flutter container.

## Features

- Interactive breathing interface
- Responsive layout
- PWA support
- Offline caching experiments
- Communication with native Flutter functionality
- TypeScript-based frontend architecture

## Technologies

- Next.js
- React
- TypeScript
- Progressive Web App APIs
- Flutter web handler integration
